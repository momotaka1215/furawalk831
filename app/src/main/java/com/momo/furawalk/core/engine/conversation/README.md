# 会話システム (Conversation Module)

このパッケージは、ペットの会話ロジックを独立して管理するためのモジュールです。

## 目的
ペットの「思考」と「発言」を他の育成ロジックやUIから切り離すことで、将来的な会話パターンの大規模な追加や、複雑な条件（場所、時間、親密度など）への対応を容易にすることを目的としています。

## 主要コンポーネント
- **Dialogue.kt**: 会話の出力モデル（テキスト、感情、表示時間）。
- **DialogueTemplate.kt**: 会話の「型」と出現条件の定義。
- **DialogueRepository.kt**: 大量の会話テンプレートを保持するデータソース。
- **DialogueEngine.kt**: 現在の状態から「今、最も話すべきこと」を選択・生成する思考エンジン。

## 拡張ガイド
新しいセリフを追加する場合は、`DialogueRepository.kt` の `init` ブロックに `addTemplate` を追加してください。
将来的に会話データをJSONファイル等で管理する場合も、このパッケージ内のみの変更で対応可能です。
